r"""
========================================
정규표현식 기본 정리 (Python / pandas)
========================================

[ 글자 하나 ]
.       아무 글자 하나 (줄바꿈 제외)          J.ws      → Jaws, Jows
\d      숫자 하나 [0-9]                      \d\d      → 19, 42
\D      숫자가 아닌 글자 하나
\w      영문자·숫자·_ 하나 (한글도 포함)       \w+       → Jaws, 죠스
\W      \w가 아닌 글자 하나 (공백, 기호 등)
\s      공백 하나 (스페이스, 탭, 줄바꿈)
\S      공백이 아닌 글자 하나

[ 글자 묶음 ]
[abc]   a, b, c 중 하나
[a-z]   소문자 하나
[A-Z]   대문자 하나
[0-9]   숫자 하나 (= \d)
[가-힣]  한글 한 글자
[^abc]  a, b, c가 아닌 글자 하나 (대괄호 안의 ^는 "제외")

[ 반복 ]
*       앞 글자 0번 이상                      ab*       → a, ab, abbb
+       앞 글자 1번 이상                      \d+       → 3, 1983
?       앞 글자 0번 또는 1번 (있어도/없어도)   colou?r   → color, colour
{n}     정확히 n번                           \d{4}     → 1983
{n,}    n번 이상
{n,m}   n번 이상 m번 이하                     \d{2,4}   → 19, 198, 1983

*? +?   최소한으로 매칭 (게으른 매칭)          \(.*?\)   → 괄호 하나씩 따로

[ 위치 ]
^       문자열 시작                           ^The      → The로 시작
$       문자열 끝                             min$      → min으로 끝
\b      단어 경계                             \bJaws\b  → "Jaws"만, "Jawsome" 제외

[ 또는 / 묶기 ]
a|b     a 또는 b                             Movie|TV Show
(...)   묶기 + 추출 (str.extract에서 사용)     (\d+) min → 99
(?:...) 묶기만, 추출 안 함 (contains에 사용)   Jaws (?:2|3)
(?P<이름>...)  이름 붙여 추출                 (?P<year>\d{4})

[ 특수문자를 글자 그대로 찾기 ]
. ^ $ * + ? { } [ ] \ | ( )  → 앞에 \ 붙이기   \.  \(  \?
변수로 받은 값은 re.escape(값) 사용

[ 옵션 ]
(?i)    패턴 맨 앞에 붙이면 대소문자 무시      (?i)jaws  → Jaws, JAWS
case=False                  pandas str.contains에서 대소문자 무시
flags=re.IGNORECASE         re 함수, pandas extract 등에서 대소문자 무시

========================================
pandas 메서드
========================================
str.contains(pat, case=False, na=False)   어디든 포함되면 True
str.match(pat)                            맨 앞부터 맞으면 True
str.fullmatch(pat)                        전체가 맞아야 True
str.extract(r"(...)")                     ( ) 부분 첫 번째 것 추출
str.findall(pat)                          매칭 전부를 리스트로
str.replace(pat, new, regex=True)         바꾸기 (regex=True 꼭 쓰기!)
str.split(r",\s*")                        패턴 기준으로 나누기
str.count(pat)                            매칭 개수
df.filter(regex=pat)                      컬럼 이름으로 고르기

========================================
re 모듈 (import re)
========================================
re.search(pat, s)      어디든 첫 매칭 찾기 (없으면 None)
re.match(pat, s)       맨 앞에서 매칭
re.fullmatch(pat, s)   전체 매칭
re.findall(pat, s)     매칭 전부 리스트로
re.sub(pat, new, s)    바꾸기
re.split(pat, s)       나누기
re.escape(s)           특수문자를 글자 그대로 처리

========================================
자주 쓰는 패턴
========================================
r"\d{4}"              4자리 연도
r"(\d+)\s*min"        "99 min"에서 99
r"(\d+)\s*Seasons?"   "1 Season", "3 Seasons"에서 숫자
r",\s*"               쉼표 + 뒤 공백 (나라·출연진 나누기)
r"\s+"                공백 여러 개 (하나로 바꿀 때)
r"\(.*?\)"            괄호와 그 안 내용
r"^\s*$"              빈 칸 또는 공백뿐인 칸
r"[가-힣]+"            한글 단어

========================================
주의
========================================
- 패턴은 항상 r"..." 로 쓰기 (\b가 백스페이스로 바뀌는 문제 방지)
- f-string과 같이 쓸 때는 rf"...", 반복 횟수 중괄호는 {{4}}처럼 두 번
- str.contains("")는 모든 행이 True → 빈 리스트 join 주의
- 테스트: https://regex101.com (FLAVOR를 Python으로)
"""


r"""
========================================
pandas 문자열 (.str 붙여서 사용)
========================================
str.split(',')        구분자로 잘라서 리스트로
str.strip()           앞뒤 공백 제거
str.lstrip()          왼쪽 공백 제거
str.rstrip()          오른쪽 공백 제거
str.lower()           소문자로
str.upper()           대문자로
str.title()           단어 첫 글자만 대문자로
str.replace(a, b)     a를 b로 바꾸기 (정규식이면 regex=True)
str.contains(pat)     포함 여부 True/False
str.startswith(s)     s로 시작하면 True
str.endswith(s)       s로 끝나면 True
str.len()             글자 수
str.get(i)            리스트/문자열의 i번째 값
str.join(',')         리스트를 하나의 문자열로 합치기
str.extract(pat)      정규식 ( ) 부분 뽑기
str.findall(pat)      정규식 매칭 전부 리스트로
str.count(pat)        패턴 개수
str[:5]               앞 5글자 자르기 (슬라이싱)

========================================
Series 값 정리 (.str 없이 사용)
========================================
explode()             리스트를 한 줄에 하나씩 펼치기
unique()              중복 제거한 값들
nunique()             중복 제거한 값의 개수
value_counts()        값별 개수 (많은 순)
drop_duplicates()     중복 행 제거 (Series 형태 유지)
isin([...])           목록 안에 있으면 True
between(a, b)         a 이상 b 이하면 True
isna() / notna()      빈 값이면 True / 아니면 True
fillna(값)            빈 값 채우기
astype(int)           타입 바꾸기
sort_values()         정렬
head(n) / tail(n)     앞 n개 / 뒤 n개
tolist()              파이썬 리스트로 변환

========================================
파이썬 기본
========================================
sorted(x)             정렬해서 새 리스트로
len(x)                길이
set(x)                중복 제거 (순서 없음)
", ".join(list)       리스트를 문자열로 합치기
"a,b".split(",")      문자열을 리스트로
"  a ".strip()        앞뒤 공백 제거
"""


"""enumerate.
enumerate(리스트, 시작번호): 반복할 때 (번호, 원소)를 한 쌍으로 꺼내줌
예) enumerate(['a', 'b'], 1) → (1, 'a'), (2, 'b')
for i, row in enumerate(data, 1): i = 순번(1부터), row = data의 원소(dict)
→ range(len(data))로 인덱스를 만들어 data[num]으로 꺼내는 것보다 간단함
"""

"""zip.
zip(리스트1, 리스트2): 같은 위치의 원소끼리 짝지어서 (값1, 값2)로 꺼냄
예) zip(['A', 'B'], [2020, 2021]) → ('A', 2020), ('B', 2021)
for title, year in zip(titles, years): 두 리스트를 동시에 반복
길이가 다르면 짧은 쪽에 맞춰서 끝남
"""
